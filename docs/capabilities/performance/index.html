Engineering responsibility

Performance is not one number.

API workload behavior, public browser rendering and authenticated browser rendering measure different risks and therefore use different execution models.

01

API workload

k6 measures authenticated task-read behavior under a controlled baseline load.

02

Public browser

Lighthouse CI evaluates a public application entry point using three independent measurements and assertion-based policy.

03

Authenticated browser

Playwright establishes authenticated state before Lighthouse measures the protected dashboard.
